FLICKER BISECTION

Each box below is the same field of blobs, drawn the same way. They differ by one thing each. Click inside every box a few times and note which ones show the pale grey film. That names the cause without guessing.

Every box repaints on click, so a box that never flashes rules out the drawing itself. If only 2 flashes it is pointer capture. If only 3, text selection. If only 4, the panel's compositing layer. If 1 flashes too, it is the canvas or the browser and nothing the page does.
